## Codebase Patterns

### 已发现的架构模式
- **蓝图模式 (Blueprint Pattern)**: 使用 Flask Blueprint 分离 API 路由和 Webhook 处理
- **分层架构**: 数据层 (models.py) → 业务层 (utils.py) → API 层 (routes.py, webhooks.py)
- **ORM 模式**: SQLAlchemy 2.0+ 类型化 Mapped 注解
- **依赖注入**: current_app.extensions['sqlalchemy'] 获取数据库实例

### 核心模块结构
```
backend/
├── emailhandler/          # 数据层
│   ├── models.py         # SQLAlchemy 模型（Mailbox、Email、Attachment）
│   ├── email_monitor.py  # v2.0 遗留代码
│   └── link_handler.py   # v2.0 遗留代码
└── api/                   # API 层
    ├── __init__.py       # 蓝图导出
    ├── routes.py         # RESTful API（5个端点）
    ├── webhooks.py       # Webhook 处理（1个端点）
    └── utils.py          # 工具函数（验证链接提取）
```

### 关键技术点
1. **模型关系**: Mailbox (1:N) Email (1:N) Attachment，级联删除
2. **Webhook 认证**: X-Webhook-Secret 请求头验证
3. **验证链接提取**: 5 个正则表达式模式顺序匹配
4. **事务管理**: try-except + db.session.rollback()
5. **分页查询**: pagination.paginate() 方法
6. **CORS 配置**: 支持多源配置（逗号分隔）
